# 文径首屏与起步路径优化

## 目标

把新用户第一次打开文径时看到的“开始页”改成清楚、有人味、能立即行动的起点：用户先选真实交付，再填主题与期限；页面不制造压力、不预设结论，也不让模板信息抢走注意力。

## 任务

- [ ] 重写首屏与起步提示文案，删除空泛口号、任意数量承诺和过度解释。
- [ ] 重排桌面端首屏比例、卡片信息层级与留白，降低标题压迫感。
- [ ] 调整移动端首屏高度、卡片节奏和可触达区域，保持完整操作路径。
- [ ] 让选择模板后的顶部提示明确反映“已选起点”，并引导填写真实主题与期限。
- [ ] 增加起步页的可访问性入口与回归测试。

## 验收标准

- 首屏能在一眼内回答“这是做什么、从哪里开始、下一步是什么”。
- 桌面端不再出现大面积空白和过度巨大的标题；三张卡片均能快速扫读。
- 390px 宽移动端不横向溢出，卡片和按钮保持可点击，模板选择后能进入研究边界。
- 旧的“不是一堆链接”“50 分钟”等文案不再出现在起步路径中。
- 现有功能测试、语法检查、构建与密钥扫描全部通过。
