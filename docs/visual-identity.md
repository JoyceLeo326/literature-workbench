# 文径视觉识别与叙事资产

## 品牌核心

“文径”不是替用户给出结论的黑箱，而是一条能从问题走回证据、也能从反馈重新出发的研究路径。标志由三部分组成：展开的书页代表原始材料；矿物青色路径代表可复查的证据链；朱砂书签代表人在关键处作出的判断。英文标识统一使用 `WENJING`，不再使用旧称 `LITPATH`。

基础色为暖象牙 `#F5F0E5`、墨色 `#17201D`、矿物青 `#2C7772` 与朱砂 `#C54A38`；金色 `#D59B48` 只用于“证据节点”和完成状态。界面使用系统字体栈，不从外部字体服务加载资源。

## 连续故事

24 幅插画分成六章，每章四个场景：让问题落地、在噪声中取舍、让证据互相照见、从材料走向论证、把研究交到别人手里、把反馈变成下一轮。主角林的深青针织衫与象牙衬衫贯穿多数画面；方法顾问与档案员在第三、第四幕作为协作角色进入。每幅图都对应一个真实产品动作，图像、场景标题、说明、下一步按钮和反馈路由共同工作，不作为装饰性占位。

| 范围 | 画面 | 产品作用 |
| --- | --- | --- |
| 01–04 | 提问、边界、检索路线、候选潮 | 引导建立范围与检索留痕 |
| 05–08 | 取舍、冲突证据、排除台账、导师检查 | 解释筛选权衡与遗漏风险 |
| 09–12 | 原文摘录、证据星座、偏差复查、同伴协商 | 支撑核验、分歧与反思 |
| 13–16 | 论证、结构比较、引用追溯、限制 | 支撑综合写作与可解释边界 |
| 17–20 | 交付选择、同行复查、反馈回流、证据包 | 串联交付与反馈闭环 |
| 21–24 | 移动续接、导师交接、下一轮、日出 | 表达跨场景连续性与迭代 |

## 真实性与使用边界

这些画面是为文径生成的叙事插画，不是研究现场照片，也不代表真实人物、真实论文或真实研究结论。它们只帮助用户理解工作流；所有文献字段、筛选判断、证据等级与交付内容仍来自用户录入并由用户负责核验。源图经本地压缩为自托管 WebP，不依赖第三方图片 CDN；品牌板保存在 `assets/brand/wenjing-brandkit-v1.png`，站内标志保存在 `assets/brand/wenjing-mark.svg`。
