# 文径 · 文献研究工作台

文径是一套本地优先的文献整理工作台，将文献任务拆成六个连续环节：

- 在线体验：https://literature-workbench.vercel.app/
- 作品演示托管：Vercel Hobby（仅限个人、非商业用途）

1. 明确研究边界；
2. 生成并记录中英文检索式；
3. 录入和维护文献题录；
4. 逐条完成筛选决定与证据综合；
5. 检查重复、缺失与来源问题；
6. 导出 CSV、完整 JSON、BibTeX、Markdown 综合和质量检查报告。

## 核心功能

- 自定义中文/英文目标数量、交付日期、年份范围和纳入/排除条件；
- 从概念组生成布尔检索式，并记录检索平台、时间和结果说明；
- 维护标题、摘要、作者、作者单位、年份、来源、DOI、链接、PDF 文件名等字段；
- 支持检索、语言/状态筛选、批量核验、编辑和删除；
- 在“文献目录”和“质量检查”之间提供“筛选与综合”工作区，逐条保存筛选决定、排除理由、核心发现、人工证据等级和主题标签；
- 提供筛选统计，以及可按决定、证据等级、主题和文本过滤的证据矩阵；
- 根据当前已纳入记录的字段完整度与主题分布给出研究空白提示；这些提示不构成系统综述结论，也不替代研究者回到原文判断；
- 按规范化题名与 DOI 检测疑似重复，定位缺失字段和来源不可追溯记录；
- 导入 CSV、JSON、BibTeX 与 RIS，导出 UTF-8 BOM CSV、BibTeX、完整 JSON、Markdown 证据综合和文本质量报告；
- 完整 JSON 备份与再次导入会保留全部筛选与综合字段；
- 输入 DOI 后可通过 Crossref 公共接口补全题名、作者、年份、来源和原文链接；
- 按中英文分别生成规范化 PDF 文件名，并在导入时自动补齐缺失文件名；
- 使用 `localStorage` 自动保存，数据不上传服务器；
- PWA 离线缓存，支持桌面与移动端。

## 成本与服务边界

项目默认使用 `COST_MODE=zero_owner_cost`：不配置所有者侧付费 API、后台服务或自动账单。Crossref 公共接口失败或超限时会明确停止联网补全，手动录入、导入、筛选、综合和导出仍可继续。

当前线上地址只作为 Vercel Hobby 个人、非商业作品演示。商业部署候选、`localStorage` 现状，以及尚未实现的 IndexedDB / BYOS 路线见 [项目所有者零固定成本策略](docs/zero-owner-cost.md)。

## 本地运行

```bash
python3 -m http.server 4173
```

打开 `http://localhost:4173`。

## 数据说明

工作台默认不包含正式文献数据。用户可以手动添加、导入自己的目录，或使用“载入演示数据”查看功能。演示记录均带有明确标识，不应进入正式交付。

证据等级由使用者人工标注。工作台不会自动判定研究质量、生成正式文献结论或声称已经完成系统综述。

## 技术栈

无框架 HTML / CSS / JavaScript，无后端依赖。所有数据在浏览器本地处理和保存。

## 已验证场景

- 320、390、768、1024、1440 像素视口无横向溢出；
- DOI 自动补全，CSV / JSON / BibTeX / RIS 导入；
- 筛选决定与综合字段本地持久化，证据矩阵组合过滤，完整 JSON 往返保留；
- 重复项、缺失字段与来源待核检查；
- CSV、JSON、BibTeX、Markdown 综合与质量报告导出；
- Service Worker 缓存与离线重载。

核心筛选、综合与零成本策略可使用 Node 内置测试运行：

```bash
node --test tests/literature-synthesis.test.cjs tests/zero-owner-cost.test.cjs
```
