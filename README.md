# 文径 · 文献研究工作台

[打开文径（GitHub Pages）](https://joyceleo326.github.io/literature-workbench/) · [备用入口（Vercel）](https://literature-workbench.vercel.app/)

文径把一项文献任务拆成可复查的连续流程：定义研究边界、选择研究策略、建立检索式、维护题录、完成人工筛选与证据综合、检查质量、整理交付。研究阶段、交付目标、时间、语种缺口、题录进度和现场反馈会共同生成三条差异化策略；每条都明确收益、代价、适用依据与第一步行动。访客可以直接开始工作，账户入口始终是自主选择。

## 一条会被反馈改写的研究故事

总览中的 24 幅连续画面覆盖提问、边界、检索、筛选、核验、综合、交付与迭代六章。它不是与功能分离的展示画廊：当前研究阶段、交付目标、文献数量、核验进度会决定建议进入的章节；用户保存“范围太宽、来源不足、结论过强、结构不清或难以交接”等反馈后，故事入口、下一步任务和交付报告会一起变化。完整的视觉识别、场景清单与插画真实性边界见 [视觉识别与叙事资产](docs/visual-identity.md)。

## 核心工作流

1. 为每个研究项目设置问题、年份、目标数量、纳入条件与排除条件。
2. 比较三条研究策略的收益与代价，选择并明确接受取舍后人工确认 V1。
3. 从中英文概念组生成布尔检索式，并记录检索平台、时间与结果说明。
4. 手动录入或导入 CSV、JSON、BibTeX、RIS 题录；DOI 仅做格式校验，题录字段仍由使用者依据原文填写。
5. 逐条保存筛选决定、排除理由、核心发现、人工证据等级与主题标签。
6. 将真实结果带回决策台，先查看 V2 事实差异，再次人工确认；旧版本始终保留。
7. 导出 UTF-8 BOM CSV、完整 JSON、BibTeX、策略版本、Markdown 证据综合与质量报告。

研究画像并非装饰字段：课程研究、论文阶段和工作研究对应不同的证据节奏；课堂汇报、开题方案和文献综述会改变边界相关、来源追溯、字段完整、时间新近、反证分歧五项权重，投入时间决定单轮批次。语种缺口与上一轮反馈继续重排检索路线和题录优先级，并解释每条记录为什么先处理。研究画像、人工选择、现场补充与版本差异都会写入项目备份和交付文件。

## 产品能力

- 多研究项目创建、切换与自动保存；
- 标题、摘要、作者、单位、年份、来源、DOI、原文链接、PDF 文件名等完整题录字段；
- 独立的筛选与综合工作区，以及语言和状态筛选、批量核验、编辑、删除与最近更新；
- 画像驱动的检索路线、可解释证据权重与优先复核队列；
- 三候选研究策略、显式取舍确认、反馈驱动的 V2 提案与完整版本账本；
- 规范化 PDF 文件名与交付清单；
- 完整 JSON 往返保留筛选和综合字段；
- 六章 24 幕研究叙事、研究画像推荐入口与反馈驱动的下一轮路径；
- PWA 离线重载与桌面、平板、手机响应式布局。

证据等级与研究结论始终由使用者判断。字段分布提示只反映当前项目中的资料，不代替回到原文核验，也不构成系统综述结论。

## 项目与账户

研究项目会持续保存，登录与注册保持可选；完整 JSON 可随时导出并再次导入。核心交互不依赖境外运行时 API、字体或 CDN；文径不会代替使用者填写来源、证据等级或研究结论，也不会在前端保存任何 AI API 密钥。
