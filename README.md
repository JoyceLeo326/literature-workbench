# 文径 · 文献研究工作台

文径是一套本地优先的文献整理工作台，将紧急文献任务拆成五个连续环节：

1. 明确研究边界；
2. 生成并记录中英文检索式；
3. 录入和维护文献题录；
4. 检查重复、缺失与来源问题；
5. 导出 CSV、JSON、BibTeX 和质量检查报告。

## 核心功能

- 自定义中文/英文目标数量、交付日期、年份范围和纳入/排除条件；
- 从概念组生成布尔检索式，并记录检索平台、时间和结果说明；
- 维护标题、摘要、作者、作者单位、年份、来源、DOI、链接、PDF 文件名等字段；
- 支持检索、语言/状态筛选、批量核验、编辑和删除；
- 按规范化题名与 DOI 检测疑似重复，定位缺失字段和来源不可追溯记录；
- 导入 CSV、JSON、BibTeX 与 RIS，导出 UTF-8 BOM CSV、BibTeX、完整 JSON 和文本质量报告；
- 输入 DOI 后可通过 Crossref 公共接口补全题名、作者、年份、来源和原文链接；
- 按中英文分别生成规范化 PDF 文件名，并在导入时自动补齐缺失文件名；
- 使用 `localStorage` 自动保存，数据不上传服务器；
- PWA 离线缓存，支持桌面与移动端。

## 本地运行

```bash
python3 -m http.server 4173
```

打开 `http://localhost:4173`。

## 数据说明

工作台默认不包含正式文献数据。用户可以手动添加、导入自己的目录，或使用“载入演示数据”查看功能。演示记录均带有明确标识，不应进入正式交付。

## 技术栈

无框架 HTML / CSS / JavaScript，无后端依赖。所有数据在浏览器本地处理和保存。
